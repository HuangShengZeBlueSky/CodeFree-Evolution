# 完整显式 YAML 合同

字段和注册组件以 MD 指定的当前运行时 Schema 为准。固定运行时及工具实现后，完整 YAML 是被测 Agent **可优化行为的唯一配置源**；工具函数实现、模型服务和环境数据是明确绑定的执行依赖，不能因此偷偷补行为配置。

## 必须明确写出的内容

- 模型与生成参数、系统指令、错误/重试/终止等有行为意义的设置。
- 全部工具的名称、description、完整参数 JSON Schema、调用前参数/业务规则及调用后增强。
- 记忆的字段、更新指令和时机；压缩阈值、保留范围和全部摘要指令；任务技能定义、正文/固定内容引用与加载方式。
- 每个注册组件的引用及完整参数；外部政策、工具绑定和其他行为依赖的显式声明与固定身份。

工具缺失或多余、description 空值、参数 Schema 缺失、必需行为字段缺失均启动失败。无参数工具也明确声明 object、空 properties 和 required。不能从 docstring 自动补说明、从函数反射补漏字段、从上个候选继承增强，或通过环境/构造器开关额外注入经验。初始化可显式导出一次工具快照，核验冻结为 Parent；执行时不能重新补全。

## 全组件开启

本实验默认记忆、压缩、任务技能、参数校验、业务校验、结果增强全部开启且有真实内容。每类至少有适用的字段、技能或规则，不能用空集合配 `enabled: true` 冒充开启。按工具实际能力应用规则；某个工具不适用的规则用 Schema 定义的空值明确表示，同时保持整类组件启用且存在适用配置。

优化复制完整 Parent，仅修改选定字段并保留其他组件有效。关闭组件属于消融，只能在用户明确要求且 MD 记录后进行。`null`、空列表和关闭开关必须有固定语义，绝不表示继承默认值。

## 必须由运行证据支持的结论

记录 YAML 哈希、运行时和依赖身份；将实际主模型请求中的工具描述、参数和指令与 YAML 核对。检查参数/业务校验、结果处理、记忆、技能和压缩事件是否发生，以及结果是否送达下一次请求。生成有效配置快照不能代替模型请求证据。

真实执行和评分回放使用同一工具/组件契约。加载器若仍存在外部行为覆盖，应在配置允许范围内修复并重新验证；不能写一句合同就声称运行时已保证。不同候选使用隔离实例，验证重复加载不会保留前一候选的增强。
