# 调度、真实运行与恢复

监控按 MD 指定方式创建或复用归因、优化会话，登记实际返回的会话 ID、工作目录和输入输出。先派发归因并等待可验收报告，再派发优化；显式等待任务完成并读取实际产物。只有监控推进实验预算循环。写出交接文件不代表另一个角色已经执行。

启动先核实配置中的运行时、Schema、工具实现、模型入口和评分接口可用，准备完整 Parent。执行项目原生加载检查和获授权范围内的小样本，确认从 YAML 到模型请求、工具调用、日志导出和评分的路径可运行，再按配置跑基线与搜索。禁止运行时补默认、环境开关注入、命令覆盖 YAML 行为或跨候选遗留状态；遇到这类入口应修复运行时，不能靠 skill 提醒掩盖。

每个新 Parent 验证全部开启的组件有实际内容和合法配置。参数/业务校验分别检查合法与非法输入，确保副作用前拦截；结果增强保持事实真实；记忆检查后续请求读到更新；任务技能检查正文送达；压缩需用足够长的历史触发并检查关键事实保留。组件专项检查使用项目已有原生接口或测试，不给角色 skill 增加 benchmark 专用 checker。

正式评测与修改生效证据分开记录：短任务未触发压缩如实写未触发，另记专项验证；组件 probe 通过不能代替 benchmark 成绩。必须保留真实模型请求、调用事件、结果与运行身份，不能以模拟分数、手写 passed/promoted 或未经运行的样例报告冒充完成。

按 MD 收齐本 attempt 的有效结果后执行 Gate 和晋升规则；无可处理 scope 时按配置结束或重新选题。归因、优化角色不自行跳过 Gate 或修改分母。新 Parent 重新归因，同 Parent 的复用和同轮 scope 规则由 MD 明确。

中断恢复先核对配置哈希、Parent、scope、run_id、会话和已有结果，复用已验收产物，避免重复副作用。执行失败保留有效证据，按配置重试或停止；预算耗尽也必须如实给出完成和未完成项。
